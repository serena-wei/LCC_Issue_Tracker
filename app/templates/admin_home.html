Welcome to the Lincoln Community Campground (LCC) Issue Tracker

This system helps you quickly report campground issues and track their resolution progress. Your current role is Admin.

As an admin, you can:

  • Register a new account
  • Reset your password
  • View and update your personal information
  • View issues created by any user
  • Comment on issues created by any user
  • Update the status of issues
  • See comments from all users on issues
  • View the complete user list
  • Search for users by username, first name, or last name
  • View all users' profile details
  • Modify user statuses
  • Change user roles
